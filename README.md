### 🔭 What I'm building

**PRISM - Predictive Risk Intelligence for Service Management**
An end-to-end ML platform predicting chassis-level customer dissatisfaction from service, complaint, and warranty data.
- Random Forest classifier (~82% weighted F1)
- Six-tab Streamlit dashboard with role-based access control (Viewer / Admin)
- PostgreSQL backend
- AI Analyst agent (Azure OpenAI / Groq) for natural-language querying of dissatisfaction patterns
- Presented to stakeholders as a business decision-support tool

**Wholesale Demand Forecasting Pipeline** *(in progress)*
A forecasting system for tractor models, currently under development.
- XGBoost with walk-forward cross-validation
- Handles model lifecycle transitions, cold-start scenarios, and discontinued-model decay
